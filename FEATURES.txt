MX Force Studio - features
==========================

- Own desktop window on this PC only (offline after first install)
- Live 6DOF garage that follows MX Bikes on the same PC
- Rec (top left): record, replay, fullscreen, widget (small view)
- MX Bikes replay scrubs the matching Force Studio take by session time
- Right panel toggles 49 individual bike parts (default: frame, seat, plastics, bars)
- Compact MX cradle rig: 1.17 x 1.21 m footprint, 44 deg lean, 41 deg pitch
- Frame bolts into cradle clamps on the load plate; MX rider leans with telemetry
- Pull-out left (inputs) and right (session / recordings) panels
- Reads your MX Bikes controller binds on connect (sit / lean / triggers)
- Shortcut: MX Bikes plugins.lnk -> game plugins folder
- Installer starts the app. Updater only downloads; it does not start it
- UPDATES.txt is the revision log. Its id line is how you tell if this install is current

How it works
------------
1. Double-click Installer.bat. First run needs internet.
   If startup fails, that window stays open and prints the reason.
2. After that the app runs on this PC with no URL to join.
3. Start MX Bikes, go on track. Live is already on.
4. Updater.bat rebuilds and shows UPDATE READY with the id from UPDATES.txt.
   It does not open the garage. Use Installer.bat to start.
5. Close the Force Studio window to stop. Uninstaller.bat removes
   icons, cache, and the plugin.

Riders only need: Installer.bat, Updater.bat, Uninstaller.bat.
